Epyrus Privacy Statement

Epyrus is designed to operate entirely on the user's device. The application does not collect, store, transmit, or process personal data on behalf of the user.

  1. No Telemetry

    2. Epyrus does not include telemetry, analytics, usage reporting, crash reporting, or any other form of data collection. The application does not send information to the developer or to any third-party analytics service.

  2. Local Processing

    3. All information handled by Epyrus (including e-mail content, account settings, address books, and configuration data) remains on the user's device unless the user explicitly chooses to transmit it (for example, by sending e-mail through their mail provider).

    Epyrus does not operate any cloud services and does not sync data to any external servers.

  3. Network Connections

    4. Epyrus connects only to services the user configures, such as:

    • IMAP/POP mail servers
    • SMTP servers
    • Add-on update servers
    • Application update servers (if enabled)

    These connections occur only to perform the functions the user requests.

    IP Addresses

    When Epyrus checks for updates or downloads add-ons, the server providing those files may log the user's IP address as part of normal web server operation. Epyrus does not control these servers and does not receive or store these logs.

  4. Third-Party Services

    5. Any data exchanged with third-party services (such as your e-mail provider or add-on repositories) is governed by the privacy policies of those services. Epyrus is not responsible for the behavior, data handling, or logging practices of third‑party servers.

  5. No Accounts, No Tracking

    6. Epyrus does not require an account, does not track users across sessions, and does not identify users in any way.

  6. Liability

    7. Epyrus is provided "as-is" without warranties of any kind.

    athenian200 is not responsible for:

    • user configuration choices
    • third-party service behavior
    • network traffic initiated by the user
    • data handled by external servers

    Use of Epyrus is at the user's own risk.
